# ARCHITECTURE DIAGRAM COMPONENT

## PURPOSE

Animated blueprint-style dependency diagram for project detail pages.
Shows folder structure under src/ with synchronized pulse animation.
Stack: Astro component. Self-contained CSS. Zero dependencies.

## FILE LOCATION

src/content/projects/[project-slug]/assets/ArchitectureDiagram.astro

## INTEGRATION

In about.mdx at the top:
  import ArchitectureDiagram from './assets/ArchitectureDiagram.astro';

Inside the Architecture accordion:
  <Accordion title="Architecture">

  The codebase is split into clear layers:

  <ArchitectureDiagram />

  **Flow:** `pages → letter → core → db`

  Nothing skips layers. Nothing imports backward.

  </Accordion>

## WHAT IT RENDERS

Single SVG containing:
- 1 root box: src/
- 4 folder boxes: pages/, letter/, core/, db/
- Trunk line from src/ down to horizontal bar
- 4 vertical lines from bar to each folder with arrowheads
- 3 chain arrows between folders
- 7 animated pulses (4 fan-out + 3 chain)

## ANIMATION TIMING

5-second loop, 4 phases, each phase 1 second:

Phase 1 (0s-1s):  src → pages/
Phase 2 (1s-2s):  pages → letter/  AND  src → letter/   arrive together
Phase 3 (2s-3s):  letter → core/  AND  src → core/     arrive together
Phase 4 (3s-4s):  core → db/      AND  src → db/       arrive together
Phase 5 (4s-5s):  pause, restart loop

Implementation via animation-delay tokens:
  --md-sys-motion-delay-phase: 1s

  .arch-pulse-pages        { animation-delay: 0s; }
  .arch-chain-pages-letter { animation-delay: var(--md-sys-motion-delay-phase); }
  .arch-pulse-letter       { animation-delay: var(--md-sys-motion-delay-phase); }
  .arch-chain-letter-core  { animation-delay: calc(var(--md-sys-motion-delay-phase) * 2); }
  .arch-pulse-core         { animation-delay: calc(var(--md-sys-motion-delay-phase) * 2); }
  .arch-chain-core-db      { animation-delay: calc(var(--md-sys-motion-delay-phase) * 3); }
  .arch-pulse-db           { animation-delay: calc(var(--md-sys-motion-delay-phase) * 3); }

## ADAPTING FOR A NEW PROJECT

Change these elements when folder structure differs:

1. FOLDER NAMES
   Update SVG <text> contents to match new folder names.

2. FOLDER COUNT
   4 folders: default layout works as-is
   5 folders: reduce box width to 110px, adjust x positions
   3 folders: widen boxes to 140px, adjust x positions
   2 folders: widen to 160px, remove middle chain arrow

3. X POSITIONS
   Root src/ centered at x=450 in 900-wide viewBox.
   Distribute 4 folders evenly: 120, 340, 560, 780.
   Recalculate if count differs.

4. PULSE PATHS
   Each pulse path d attribute must start at src/ trunk,
   follow the horizontal bar, then drop to folder center.
   Chain pulses go from right edge of one folder to left edge of next.

5. COLOR PALETTE
   If project uses different colors, change only the two
   color blocks (light + dark). Keep token names identical.

## CONSTRAINTS

- No CSS comments anywhere
- No self-referencing system tokens
- No inline styles outside SVG
- No hardcoded hex values outside token definition blocks
- Must respect prefers-reduced-motion
- Must work in light and dark with zero JavaScript
